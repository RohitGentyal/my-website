# my-website

Personal portfolio. Plain HTML, CSS and JS, no build step.

- `index.html` — page content (intro, work list, about)
- `style.css` — layout and colour tokens
- `scene.js` — the painted hillside on a canvas (flat, brushy planes of green and one tree), plus placing the listener drawn in `index.html` on the slope. Set `PLAYLIST_URL` in `scene.js` to make the listener open the playlist.

Run locally: `npx serve . -l 5174`
