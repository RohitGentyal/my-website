# my-website

Personal portfolio. Plain HTML, CSS and JS, no build step.

- `index.html` — page content (intro, work list, about)
- `style.css` — layout and colour tokens
- `scene.js` — the painted hero on a canvas: teal sky, one cumulus, a grassy slope with a sandy path and rocks, all from seeded brush marks. Set `PLAYLIST_URL` in `scene.js` and mark a link with `data-playlist` to add the music link.

Run locally: `npx serve . -l 5174`
