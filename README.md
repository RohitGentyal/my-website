# my-website

Personal portfolio. Plain HTML, CSS and JS, no build step.

- `index.html` — page content (intro, work list, about)
- `style.css` — layout and colour tokens (light and dark)
- `scene.js` — the hand-drawn hillside: football goal, a controller whose cable becomes a tree root, gym weights, and poems falling from the tree. Hover the underlined words to light up each part.

Run locally: `npx serve . -l 5174`
